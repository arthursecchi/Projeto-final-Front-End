## Sobre o projeto

Site educativo sobre prevenção em saúde, cuidados com cães e gatos e Saúde Única em João Pessoa (PB). O guia de unidades reúne links oficiais para consultar serviços de atendimento na cidade.

## Páginas do site

- **Início** — apresentação do projeto e acesso às demais páginas.
- **Unidades** — guia com filtro para todas as unidades, saúde humana ou saúde animal.
- **Saúde humana** — informações sobre prevenção da dengue, higiene, vacinação e saúde mental.
- **Saúde pet** — cuidados de rotina com cães e gatos e serviços de proteção animal.
- **Saúde Única** — exemplos da relação entre a saúde das pessoas, dos animais e do ambiente.
- **Checklist** — lista de cuidados com caixas de seleção.
- **Lembretes** — modelo para anotar consultas, vacinas e outros cuidados na agenda.
- **Sobre** — objetivo do site e fontes consultadas.

## Como abrir

1. Abra a pasta `projeto final israel`.
2. Dê dois cliques no arquivo `index.html` para abrir o site no navegador.
3. Use o menu para navegar entre as páginas.

O projeto usa HTML, CSS e JavaScript. O JavaScript é usado somente no filtro da página Unidades. O site abre diretamente no navegador, sem instalação.
